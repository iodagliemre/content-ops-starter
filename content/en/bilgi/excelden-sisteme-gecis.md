# Moving from Excel to a system: a roadmap for small businesses

Excel is not a bad tool. Most businesses start there, and it does the job for a while. The problem is that Excel does not grow with the business: the file gets copied, versions multiply, nobody knows who changed what and when, it does not open on a phone, it does not remind you.

When the time to move comes, how do you do it without pain?

## Signs that Excel is no longer enough

- Two or three different versions of the same list are going around.
- "Who has the latest version?" is asked several times a week.
- The person in the field cannot reach the file and asks for a photo on WhatsApp.
- Timed work — appointments, delivery dates, document expiry — slips through.
- Rows are counted by hand for the month-end report.
- The bigger the file gets, the slower it opens; when a cell is deleted, nobody notices.

If two of these apply, it is time to consider moving. If four apply, it is overdue.

## Step 1 — Clean up the Excel, not the system

The biggest part of the move is cleaning the data. A system does not fix the mess in Excel; it carries it over. First:

- Make the column headings unique (Phone / Tel / Mobile are the same thing).
- Delete empty and duplicate rows.
- Bring dates and phone numbers into one format.
- See which columns are really used; unused columns are not carried over.

This step takes a day and makes everything easier.

## Step 2 — Start with a single process

Portfolio, customers, orders, companies — start with whichever hurts most. One process, one list, one screen. Once the team has adopted it, move on to the second.

## Step 3 — Preview the import

A good system does not take the Excel file and throw it straight in; it first shows a preview: how many rows were read, which ones are faulty, and why. You fix the faulty rows in Excel and upload again. A blind import produces rubbish that cannot be cleaned up later.

## Step 4 — A parallel period

For the first two weeks, Excel and the system run together. New records go into the system; checks are done in Excel. After two weeks, Excel becomes a read-only archive.

## Step 5 — Use it from your phone

The real gain of the move is not at the desk but in the field. If the system does not open on a phone, it is no different from Excel. The agent showing a property should see the portfolio, the specialist on site should see the company, the courier on delivery should see the order — from their phone.

## Example: a real estate office

In one real estate office, the portfolio was in Excel, the property owners in WhatsApp and the meeting notes in a notebook. During the move, the Excel was imported as a single file, 40 faulty rows (missing phone numbers, broken dates) were fixed in the preview, and the panel went into use within a week. Now the same contact card holds the property owner, the interested client and dated notes; viewing times are reminded by the panel; "how many did we rent this month" is visible at a glance.

## A note on ownership

If the system you are moving to is a rented SaaS, you are trading the freedom of Excel for someone else's limits. If the system is yours — code, data, infrastructure — you gain order without losing Excel's flexibility. Ask about that too when you make the move.
